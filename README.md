# Savik Kinger

Personal website: [skfile.github.io](https://skfile.github.io).
Static HTML, CSS, and JavaScript, hosted on GitHub Pages.

## Edit

- `index.html` — bio, research, projects, writing, and links.
- `assets/css/styles.css` — layout and styling.
- `assets/js/main.js` — section navigation and photo fallback.
- `assets/img/profile.jpeg` — profile photo. Replace this file with a JPEG using the exact same filename; no HTML changes are needed.

## Preview

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Open [localhost:8000](http://127.0.0.1:8000).

## Publish

Commit and push to `master`. GitHub Actions publishes the website automatically.

See [the editing guide](FILL-IN-GUIDE.md) for more detail.
